## 一、分层架构

```mermaid
graph TB
    subgraph 输入层
        A1[docx 论文] / A2[txt/csv/bib/ris 文献表]
    end
    subgraph 解析层
        B1[文献条目解析器 REF-01<br/>噪声鲁棒→文献参数卡]
        B2[论文解析器 M2<br/>样式树/域/四类标记→论文对象卡]
    end
    subgraph 知识层
        C1[条款库<br/>编号+条号+原文摘录+status]
        C2[versioned ruleset 四层<br/>国标2015/2025→年份→期刊→学校]
        C3[AIGC 特征库<br/>特征逐条挂依据]
    end
    subgraph 引擎层
        D1[核查与修正 REF-02]
        D2[对账 REF-04 / 去重 REF-05 / 画像 REF-06]
        D3[推荐 REF-07 + 编号重排内核]
        D4[全文线审计 FULL-01..06]
    end
    subgraph 判定与证据
        E1[三级判定 pass/fail/manual_confirm]
        E2[证据链 挂条款+位置+原文摘录]
    end
    subgraph 交付层
        F1[CLI taw<br/>单一事实源]
        F2[PySide6 GUI<br/>只消费 CLI/引擎 API]
        F3[报告导出 + 拓扑 HTML 0外链]
        F4[本地文献库 SQLite]
    end
    输入层 --> 解析层 --> 引擎层 --> 判定与证据 --> 交付层
    知识层 --> 引擎层
```

要点：
- **解析层产出统一中间表示（参数卡）**，比对/审计问题归约为结构化对齐（详设见 [04](04-模块详设.md)）；
- **引擎层全部确定性规则**；LLM 仅作可选本地兜底感知层（显式开关），只填"宁缺"槽位，**绝不产生/修改任何判定**；
- **CLI 是单一事实源**，GUI 只消费既有引擎 API，不另起第二套行为。

## 三、技术选型表

| 选型 | 版本约束 | 理由 | 启用 |
|---|---|---|---|
| Python | `>=3.8` | 本机 3.8.8（默认 py）+ 3.12.10；CI 四矩阵（ubuntu/windows × 3.8/3.12）逼出兼容写法 | M0 |
| CLI 框架 | argparse（stdlib） | 零依赖；退出码语义可控 | M0 |
| docx 解析/回写 | python-docx（extras `docx`） | 样式树/节属性/批注回写的事实标准 | M2 |
| 拓扑可视化 | pyvis `cdn_resources="in_line"`（extras `viz`） | 0 外链要求；小规模图无需前端框架 | M3 |
| 桌面 GUI | PySide6（extras `gui`） | py3.8 上 pip 自动解析 6.6.3.1（6.7+ 要求 ≥3.9）；offscreen 测试纪律见 skill | M6 |
| Word/WPS COM | pywin32（extras `com`，win32 标记） | 一键插入/批注回写联动；WPS 兼容范围 M6 实机验证 | M6 |
| 打包 | PyInstaller：py3.8 锁 `>=5.13,<6`；py3.9+ `>=6`（extras `pkg`） | 6.x 在 3.8 上 modulegraph 随机崩（系列实录）；onedir 双 exe（GUI console=False + CLI console=True） | M6 |
| 本地文献库 | sqlite3（stdlib） | 零依赖；跨论文复用/常引统计 | M3 |
| BM25/TF-IDF | 自实现（纯 Python） | 语料规模小；避免依赖漂移；算法属创新展示面 | M3 |
| LLM 兜底 | 可选，惰性导入 + 显式开关 | 只做感知兜底；`enable_thinking=false`/max_tokens 修复/摘录子串校验三件套 | 扩展 |
| 测试/CI | pytest + GitHub Actions 四矩阵 | dev extras = pytest + pyyaml（workflow 守门用） | M0 |

## 四、依赖分层（extras）

| extras 组 | 内容 | 测试期 import 覆盖 |
|---|---|---|
| （core） | **零依赖**（M0 起纯 stdlib，保持到引擎引入 docx 前） | — |
| `dev` | pytest、pyyaml | M0 起测试直接 import yaml（不用 importorskip，缺了要响） |
| `docx` | python-docx | M2 起 |
| `viz` | pyvis | M3 起 |
| `gui` | PySide6 | M6 起（offscreen，模块级 importorskip 声明式跳过） |
| `com` | pywin32（`sys_platform=='win32'`） | M6 起 |
| `pkg` | PyInstaller（按 python_version 分支版本约束） | M6 起 |

纪律（系列实录教训）：**extras 必须覆盖运行期与测试期真实 import**（FastAPI 缺 python-multipart、TestClient 缺 httpx 两类静默少跑事故）；只写下限的 pin 等于没 pin——py3.8 上的重依赖写上限；CI 与干净环境显式装 `.[dev]` 并**对照 pytest 收集数**防"双绿但悄悄少跑"。

## 五、横切工程纪律（全里程碑有效）

1. **确定性**：生成器禁 stdlib random/set 迭代序/系统时钟 → `taw.rng` splitmix64；落盘产物无时间戳，两次运行位级一致 + 守门测试；
2. **字节冻结**：`data/frozen/` 整目录入仓禁手改，改体例=固定 seed 重新生成整目录提交；`.gitattributes` `* text=auto eol=lf` + "冻结 fixtures 出现 CR 即大声失败"守门；
3. **0 外链**：拓扑 HTML/报告/演示页断网可开，测试硬断言（注意 docx .rels 的 OOXML Type URI 与 SVG 命名空间两个已知坑，按 skill 剖析口径处理）；
4. **三级判定**：status ∈ {pass, fail, manual_confirm}，证据链必挂 {规则id, 条款, 原文摘录, 位置}；
5. **LLM 边界**：不产生/不修改判定；兜底只填"宁缺"槽位；摘录不是原文子串即丢弃；
6. **类目/规则门控**：新增规则带互斥门控关键词，且对引擎**全部** check_type 生效（conditional/checklist 分支最易漏接）；
7. **CLI 契约**：exit `0`=完成 / `1`=降级完成 / `2`=用法或输入错误；`taw` 与 `python -m taw` 双入口；语义锁进 test_cli；
8. **数据目录冻结分支**：显式参数 > `TAW_DATA_DIR` 环境变量 > `sys._MEIPASS/data`（PyInstaller 6 内嵌）> exe 目录 `_internal/data`（PyInstaller 5 兼容）> CWD 上溯找 `data/`（以 README.md 标志识别）；改优先级 = 口径变更，须改测试；
9. **exe 干净验证**：中立目录 + 剥离 PATH 环境跑 CLI 通路，禁止在仓库树内验证"内嵌数据"；
10. **发布纪律**：脱敏四步 + 产物本体扫描 + 提交元数据邮箱检查（阶段 7），HANDOFF 用法行一律相对路径。
