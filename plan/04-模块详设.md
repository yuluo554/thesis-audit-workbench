# 04 模块详设

> 状态：✅ M0 定稿（schema 骨架级）。各模块实现前若需细化，在本文件追加小节并记决策；改 schema = 改口径，须重跑相关基线。

## 一、统一中间表示：参数卡

两侧输入（文献表 / 论文正文）都解析成参数卡，审计问题归约为**结构化对齐**。

### 1.1 文献条目卡 RefCard（REF-01 产出）

```json
{
  "card_id": "ref-000001",
  "entry_type": "J",                    // GB/T 7714 文献类型标识：J/M/D/C/N/R/P/S/DB/OL/A…
  "authors": [{"family": "张", "given": "三", "raw": "张三"}],
  "title": "论文题名",
  "source": {"container": "计算机学报", "year": "2024", "volume": "47",
              "issue": "5", "pages": "101-110", "publisher": null, "city": null},
  "identifiers": {"doi": "10.9999/fake.2024.001", "isbn": null, "url": null},
  "evidence": {"src": "refs.txt", "offset": 0, "raw": "原始整行文本"},
  "confidence": 0.97,
  "flags": ["hyphen_break_repaired", "fullwidth_punct_normalized"]
}
```

- `confidence`：分层噪声下逐条计算（字段齐+证据完整=高；修复性 flag 越多越低）；
- 低置信度字段**宁缺**：宁可缺失留给 manual_confirm，不得猜值硬填。

### 1.2 论文对象卡 DocObjectCard（M2 论文解析器产出）

```json
{
  "card_id": "obj-000001",
  "kind": "figure",                     // figure | table | equation | chapter | citation_marker
  "label": "图3",                        // 归一化标签（全半角/空格伪影已清洗）
  "anchor": {"para_index": 142, "style": "Normal", "is_ref_field": false},
  "mentions": [{"para_index": 210, "mode": "handwritten", "raw": "如图 3 所示"}],
  "caption_span": null
}
```

## 二、规则包与条款库 schema

条款库（`data/knowledge/`）与规则包（`data/rulesets/`）同一纪律：**每条挂出处，无 status 不得生效**。

```json
{
  "rule_id": "GBT7714-2015-punct-01",
  "scope": "reference.format",
  "standard": "GB/T 7714-2015",
  "clause": "示例：著录标点（具体条号入库时以原文核对）",
  "quote": "条款原文逐字摘录（≤125 字/引，WebFetch 通道实测上限）",
  "status": "verified | pending",       // pending=待核对：可展示、不生效、不进判定
  "severity": "error | warn | info",
  "check_type": "field_required | punct | page_range | author_threshold | consistency | ...",
  "detect": {"param": "...", "op": "...", "value": "..."},
  "fix": {"type": "auto | suggest", "template": "..."},
  "only_if_text": ["关键词门控"],        // 类目隔离门控，对全部 check_type 生效
  "gates": {"standard_year": ["2015", "2025"], "profile": ["default", "school-*"]}
}
```

四层 ruleset 叠加顺序：**国标版（2015/2025 双标尺）→ 年份版 → 期刊 profile → 学校模板 profile**，后层只做增量覆盖，覆盖动作留审计痕迹（迁移清单是 2025 版双标尺的展示面）。

## 三、三级判定与证据链

```json
{
  "rule_id": "...",
  "status": "pass | fail | manual_confirm",
  "evidence": {"clause": "条号", "quote": "原文摘录", "location": {"doc": "...", "para": 0, "span": [0, 0]}},
  "suggestion": "修正建议（auto 项带 diff）",
  "confidence": 0.0
}
```

- 多值解析/低置信度 → `manual_confirm`，**不硬判**；"待人工确认"在报告中为独立级别；
- 数值结论只来自确定性规则；报告首部强制免责声明（模板硬编码）。

## 四、四类标记体系解析（FULL-01 前置）

| 维度 | 取值 |
|---|---|
| 对象类型 | 图 / 表 / 公式 / 章节 |
| 标记模式 | Word REF 域（instrText 含 REF）| 手打编号（正则，清洗全半角与空格伪影） |
| 审计目标 | 悬空标记（提及相关对象不存在）、幽灵对象（对象从未被提及）、乱序断档 |

工程陷阱（解析器必配回归）：多行标注按 y/x 邻近聚类合并；字符逐个定位的伪空格；CRLF 残留；中文路径；GBK 控制台。

## 五、编号重排内核（REF-07 与 FULL-01 共用）

```python
def renumber(items: Sequence[NumberedItem], edits: Sequence[Edit]) -> RenumberPlan:
    """NumberedItem: {item_id, order, markers: [MarkerRef]}
       Edit: {type: insert|delete, target: item_id}
       RenumberPlan: {mappings: [{marker, old_no, new_no}], consistent: bool}"""
```

- 一致性定义：重排后**正文每个标记**都能解析到唯一新编号，且编号序列连续无断档；
- 基准：任意插入/删除位置 × 组合矩阵回归 100%（M3 文献编号、M4 对象编号各一套真值）；
- 一键插入（Word/WPS COM）走同一 RenumberPlan 落回文档。

## 六、AIGC 启发式特征表（FULL-04）

```json
{
  "feature_id": "aigc-01",
  "name": "句长均匀性",
  "detector": "sentence_length_cv",     // 实现函数名，纯本地统计
  "basis": "依据描述（公开写作风格研究/AI 高频句式观察记录，逐条挂）",
  "weight": 0.2,
  "threshold": {"warn": 0.3, "high": 0.15}
}
```

伦理边界落进 schema：报告生成器**硬编码**声明段"风险提示≠AIGC 判定，仅供作者自查改写"；仓库内**不提供**任何改写/降重通路（守卫测试断言）。

## 七、生成器真值语义（M1 数据先行时一次定清）

- 每个注入缺陷记**主期望**（主 finding 期望）；同一注入隐含的其余结论记 `also_expect`；
- 基准对账按"**文档全部非 pass 集合**"对照，防"只查注入点漏报伴生问题"；
- 互斥坑当场记录（同一参数两注入打架、多值封顶、先清旧行）；
- 全部注入类型清单随生成器落盘（`data/` 台账登记），评测报告可逐类归因。
