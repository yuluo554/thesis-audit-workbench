# 模拟赛题：参考文献全流程审计工作台（GB/T 7714 双标尺 · 引用对账 · AI 幻觉文献风险画像）

> **性质**：自拟模拟项目题（不参赛，成果发布 GitHub）。交付形式为**桌面应用 + CLI 双形态**（PySide6 + PyInstaller exe，GitHub Release 附安装包），离线即用、联网仅作显式开关的扩展模块。
> **目标产出**：GitHub 公开仓库（本地目录 `10-7-gbt7714-reference-checker`，`10-7` 为 2026-10-07 日期标签；GitHub 仓库名发布时用纯净名，待发布时确认）。
> **题目定稿**：2026-10-07 v1；同日 v2 升级（全流程审计工作台）；同日 **v2.1 增补独特功能组**（HalluRef-Bench 公开基准 / Word 批注回写 / 指纹防篡改 / 文献体检分 / 四个扩展项）。
> **核心定位（对"AI 都能改参考文献，为什么装工具"的回答）**：LLM 聊天做不了四件事——①全量批处理（300 条文献+全文远超上下文）；②可审计确定性（每处修改带 diff+条款号+内置基准，而 LLM 会编造卷期页）；③状态沉淀（本地文献库跨论文复用）；④**反向武器**（AI 正在批量生产"格式完美但不存在"的参考文献，本工具是审计防线）。本题目以 ④ 为差异化旗舰。

---

## 一、项目介绍

参考文献著录是学位论文与期刊投稿退修的高频问题；且新版 GB/T 7714—2025 已于 2026 年 7 月 1 日实施、全面替代 2015 版，期刊与学位论文正处新旧版过渡期，"双标尺"成为即时刚需。

更深刻的时代背景：LLM 辅助写作普及后，参考文献表中混入 **AI 编造文献**（真实作者+真实刊名+不存在的卷期页/DOI）的案例激增，导师与编辑亟需结构化的审计手段。LLM 对此无能为力——它自己就是问题来源，且逐条核查无法保证确定性、无法全量批处理、无法留下可审计证据。

本项目要求开发一款**参考文献全流程审计工作台**：噪声鲁棒解析 → 条款号溯源的格式核查与自动修正 → 新旧版双标尺 → **正文引用与文献表对账** → **重复条目归一** → **AI 幻觉文献结构风险画像** → 论证链矩阵与引用拓扑可视化 → 本地文献库沉淀，全离线运行、内置可复现基准。

## 二、任务要求

### 1）噪声鲁棒解析（把"简单题"变"难题"的根基）

- 输入：纯文本/Word 参考文献段/CSV/BibTeX/RIS；
- 真实文献表多从 PDF 复制而来：**断行、连字符断裂、全半角混排、空格伪影、斜体信息丢失**；
- 生成器程序化注入上述噪声，解析基准按噪声等级分层报告 F1（目标：无噪 ≥0.99、强噪 ≥0.95）；
- 输出结构化条目参数卡（作者、题名、载体类型标识 [J]/[M]/[D]/[C]/[N]/[R]/[EB/OL]、出版地/出版者、年卷期页、DOI、引用日期、获取路径），字段带置信度与原文证据；LLM 仅作可选的本地兜底感知层，结论必过确定性规则。

### 2）格式核查与自动修正（条款号溯源，v1 继承）

- 各文献类型必著录项、标点符号规则、页码/卷期格式、多作者"等/et al."阈值、电子资源引用日期；
- **全文一致性**：顺序编码制/著者-出版年制不混用、编号连续；
- 每条问题挂 GB/T 7714 条款号+规则原文摘录，三级判定；**教学解释面板**：每条错误可展开"为什么错"（条款原文+正误对照例）；
- 机械可修项自动修正（diff 高亮、逐条接受/回退），信息缺失项输出"待人工确认"补全建议。

### 3）双标尺与期刊变体（versioned ruleset 三层）

- **2015 版 / 2025 版**并行检查、差异对照报告、一键生成"迁移到 2025 版"逐条清单（GB/T 7714-2025 已于 2026-07-01 实施）；
- **期刊 profile 规则包**：期刊/学位办在国标基础上的变体要求（著录项取舍、标识符习惯）作为第三层规则包叠加——规则集架构 = 国标版 → 年份版 → 期刊版。

### 4）正文引用 ↔ 文献表对账（跨文档一致性，系列招牌能力）

- 解析正文引用标记（`[1]`、`[2,5-7]`、著者-年份制 `(Zhang et al., 2020)`）；
- 对账输出：**幽灵文献**（表有文无引）、**悬空引用**（正文引了不存在的编号/年份）、编号乱序/断档、正文著者-年份与文献表姓氏年份不匹配；
- 与格式核查共用同一套三级判定与条款/规则溯源。

### 5）重复条目检测与合并（实体归一）

- DOI 精确匹配 + 标题归一化（大小写/标点/连字符/副标题）模糊匹配 + 作者-年份辅助证据 → 重复簇识别；
- 合并建议保留信息最全条目，冲突字段"待人工确认"，不硬改；指标：去重 P/R、误合并率（目标 0）。

### 6）AI 幻觉文献风险画像（差异化旗舰，对 LLM 的反向武器）

对每条文献做**结构自洽性审计**，输出风险评分与证据（不判定真伪，只提示结构矛盾供人工确认）：

- **DOI 校验位与前缀合法性**（本地校验算法；Crossref 在线核验为显式开关扩展项，离线自动降级）；
- **时间逻辑矛盾**：出版年与卷期页组合矛盾（如 2023 年文献却见创刊早期卷号）、引用日期早于出版年；
- **作者字段异常画像**：姓名格式混乱、同一条目内作者名拼写模式断裂、机构作者与个人作者混排异常；
- **"完美格式但字段矛盾"统计画像**：AI 生成文献往往格式高度规范而事实字段组合不可能；
- 风险分级（低/中/高疑似，附逐条证据），明确声明：**风险画像不等于真伪判定，最终由人工核实**。

### 7）论证链矩阵与引用拓扑可视化

- 提取每处正文引用的上下文句（引用语境），生成**论证链矩阵**：每条文献被引次数、支撑的论点位置、从未支撑任何论点的"陈列文献"；
- pyvis 引用拓扑图 HTML（`cdn_resources="in_line"` 全内嵌、0 外链、断网可开），节点锚点与审计结论点击联动（沿用系列"报告挂可视化锚点"模式）。

### 8）本地文献库跨论文沉淀（LLM 没有的"状态"）

- SQLite 文献库：跨论文保存已核查条目；新论文导入时提示"库内已有 N 条命中"直接复用；
- 常引作者/期刊统计、按项目归档；全部本地存储零上传（未发表论文隐私红线）。

### 9）修订往返 diff（轻量）

- 两个版本文献表（如导师批注前后）逐条 diff，修改处自动尝试归类到规则条款（"导师改的是页码格式→违反 §x"），输出修订理解报告。

### 10）独特功能组（v2.1 增补，AI 时代独有）

- **HalluRef-Bench：随仓库发布的 AI 幻觉文献公开基准**——固定 seed 合成的"AI 风格编造文献"评测集（全部虚构、真值齐全、附生成器），成为社区可复现的测量标准：任何 LLM 的文献编造率、任何检测器的召回率都对着它测。工具仓库由此升格为"测量基准的家"，而不只是一个工具；
- **审计结论回写 Word 批注**——学位论文与投稿退修都发生在 Word 里：把每条审计问题以 Word 批注形式插到对应文献条目/正文引用处（操作 docx comments 部件，实现方式待核对），"检查报告"变"原位批注"，无缝进入导师-学生现有退修工作流；
- **文献表指纹与篡改检测**——投稿/送审前对文献表固化指纹快照（逐条哈希+全表哈希）；此后任何重扫（AI 二次编辑、其他格式化工具误伤、他人改动）自动 diff，并把每处变动归类到规则条款（"此处从 2015 版合规变为不合规"）——防"文献表被悄悄改"；
- **论文级文献体检分（Lighthouse 式）**——格式分/对账分/去重分/时效性（近 5 年占比）/中英文构成/自引率（本地作者名匹配可算）合成一页体检报告，答辩与投稿前 30 秒自检；
- **扩展项（显式开关，离线降级，不进基准）**：arXiv→正式发表版本升级提示（Crossref 查询"你引的预印本已见刊"）；CLI watch "文献 CI"模式（文档保存即增量审计，参考文献的持续集成）；用户自定义规则包导入导出（期刊/导师发布自家格式要求）；个人历史错误画像统计（你最常犯哪类错）。

### 11）内置评测基准（零 API 依赖，含金量核心）

- 合成文献生成器（五类文献模板 × 噪声等级 × 错误类型：标点/缺项/类型标识/著者数/编码制混用/**结构矛盾**）输出真值 JSON；
- 指标：分层解析 F1、格式检出率/误报率（误报 0）、修正准确率、对账准确率（幽灵/悬空/乱序全检出）、去重 P/R、**幻觉画像检出率（植入结构矛盾文献的识别率）**、双标尺差异检出率；指标表写进 README。

## 三、提交材料

1. 桌面应用 + CLI（PyInstaller 打包 Windows exe）；2. 核心代码框架（GitHub 公开仓库，含规则引擎、对账/归一/画像引擎与自评基准）；3. 技术报告（噪声解析方案、对账与归一算法、风险画像规则设计、versioned ruleset 三层架构）；4. 合成数据集与生成器（含真值与来源台账）；5. **HalluRef-Bench 公开评测集随仓库发布**；6. Word 批注回写与文献体检报告演示样例；7. GitHub Release：exe + 演示 GIF/截图。

## 六、边界与非目标

- **不做**：文献真伪最终判定与学术诚信结论（风险画像仅提示结构矛盾，人工确认）；查重；联网抓取元数据自动补全（仅 DOI 验证为显式开关扩展项，离线降级）；LaTeX 宏包级排版（BibTeX/RIS 仅作输入输出格式）。
- **条文纪律**：两版标准与期刊 profile 逐条挂条款号+原文核对后入库（status 字段）；查不到原文标"待核对"不得落库；幻觉画像规则全部为可解释的结构规则，不使用黑盒分类。
- **隐私红线**：全本地存储、零上传（未发表论文）；联网 DOI 验证仅发送 DOI 字符串本身，设置中明示。
- **免责**：审计结果供参考，最终格式与文献真实性以期刊/学位办及原文为准（报告带声明）。
- **品牌隔离**：不复制姊妹项目代码；文档不提其余项目业务领域。
