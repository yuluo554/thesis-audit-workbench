# 模拟赛题：毕业论文全流程审计工作台（文献审计线 × 全文审计线）

> **性质**：自拟模拟项目题（不参赛，成果发布 GitHub）。交付形式为**桌面应用 + CLI 双形态**（PySide6 + PyInstaller exe，GitHub Release 附安装包），离线即用、联网仅作显式开关扩展模块。
> **目标产出**：GitHub 公开仓库（本地目录 `10-7-thesis-audit-workbench`，`10-7` 为 2026-10-07 日期标签；原 `10-7-gbt7714-reference-checker` 于 v3 升级时改名）。
> **版本**：v1 文献格式检查器 → v2 全流程审计工作台 → v2.1 独特功能组 → v2.2 反向引用 → **v3 升级为毕业论文全流程审计工作台（A-F 全文审计线并入）**，2026-10-07。
> **定位宣言**：覆盖毕业论文**开题（综述辅助）→ 写作（反向引用、术语一致性、图表编号）→ 完稿（幻觉画像、AIGC 自检、对账）→ 送审（学校格式、结构检查单、体检分、指纹存证）**全流程的确定性审计台——LLM 聊天给不了持久状态、可审计证据与全量批处理，本工具是 AI 时代的论文质量防线。

## 一、项目介绍

毕业论文写作全流程的确定性痛点：开题时文献脉络理不清；写作中"如图 3 所示"图 3 不存在、术语全篇三种写法、参考文献被 AI 编造；完稿时 AIGC 检测成为新的送审门槛；送审前学校格式审查一票否决。市面工具要么单点（只查文献/只查错别字），要么黑盒在线服务；LLM 聊天则既不能全量批处理、也不产生可审计证据，甚至本身就是问题来源（编造文献、AI 味文本）。

本项目交付一个**两条审计线的桌面工作台**：

- **文献审计线**（v2.2 继承）：噪声鲁棒解析 → 条款号溯源核查与自动修正 → GB/T 7714 新旧版双标尺 → 正文引用对账 → 重复归一 → AI 幻觉文献风险画像 → 反向引用推荐与一键插入（编号重排）→ 论证链拓扑 → 本地文献库；
- **全文审计线**（v3 新增）：图表/公式/交叉引用审计与编号重排 → 学校格式模板核查 → 术语与数字用法一致性 → AIGC 痕迹自检（风险提示版）→ 综述辅助 → 结构检查单。

两条线共享同一套工程底座：**条款库（每条挂编号+条号+原文摘录+status）、versioned ruleset（国标→年份→期刊/学校 profile）、合成真值基准（零 API 依赖）、证据链与三级判定**。

## 二、任务要求

### 第一部分：文献审计线

#### 1）噪声鲁棒解析

纯文本/Word/CSV/BibTeX/RIS 输入；生成器注入断行、连字符断裂、全半角混排、空格伪影等噪声，分层报告解析 F1（无噪 ≥0.99、强噪 ≥0.95）；条目参数卡带置信度与证据；LLM 仅可选本地兜底感知层。

#### 2）格式核查与自动修正

必著录项、标点规则、页码卷期、著者阈值、编码制全文一致性；每条问题挂 GB/T 7714 条款号+原文摘录，三级判定；教学解释面板（条款原文+正误对照例）；机械项自动修正 diff 高亮、逐条接受/回退。

#### 3）versioned ruleset 四层

**国标版（GB/T 7714-2015 / 2025 双标尺并行与迁移清单）→ 年份版 → 期刊 profile → 学校模板 profile**；规则包 JSON 化，每条挂文号条款与 status。

#### 4）正文引用 ↔ 文献表对账

`[1]`/`[2,5-7]`/著者-年份制标记解析；幽灵文献、悬空引用、乱序断档、著者-年份不匹配，全检出。

#### 5）重复条目检测与合并

DOI 精确 + 标题归一化模糊 + 作者-年份辅助证据 → 重复簇；合并建议冲突字段"待人工确认"；误合并率 0。

#### 6）AI 幻觉文献风险画像（旗舰）

DOI 校验位与前缀合法性（本地算法，Crossref 在线核验为显式开关）、出版年与卷期页时间逻辑矛盾、作者字段格式异常画像、"格式完美但字段组合不可能"统计特征 → 风险分级+逐条证据；**风险提示≠真伪判定**。

#### 7）反向引用推荐与一键插入

句子 → 库内 BM25 检索 Top-K（附命中证据；语义 rerank 为显式开关扩展项）；**推荐候选=已审计库内文献，结构上防幻觉**；一键插入触发**顺序编码制全文编号重排**（正文标记同步，重排一致性回归 100%）；Word/WPS COM 自动化外挂（WPS 兼容范围 M6 实机验证；备用 docx 文件级；扩展 wpsjs）。

#### 8）论证链矩阵与引用拓扑

正文引用语境提取 → 每条文献支撑论点矩阵 → pyvis 拓扑 HTML（0 外链），节点与审计结论点击联动。

#### 9）本地文献库与独特功能组

跨论文 SQLite 文献库（复用提示、常引统计）；**HalluRef-Bench 公开幻觉文献基准随仓发布**；审计结论回写 Word 批注（docx comments 实现 M3 核对）；文献表指纹与篡改检测；论文级文献体检分（Lighthouse 式）；扩展项：arXiv 见刊提示、文献 CI watch、自定义规则包导入导出、个人错误画像。

### 第二部分：全文审计线（v3 新增）

#### 10）图表/公式/交叉引用审计与编号重排（A）

解析正文对图/表/公式/章节的四类标记（Word REF 域与手打编号双模式）→ **悬空标记**（"如图 3 所示"无图 3）、**幽灵对象**（图 5 从未被提及）、编号乱序断档检出；增删对象后**全文编号重排引擎**（与 §7 文献编号重排同一内核泛化）；任意插入/删除位置重排一致性回归 100%。

#### 11）学校格式模板核查（B）

python-docx 解析 docx 样式树、节属性、页眉页脚、目录 → 核对规则包：**GB/T 7713.1（学位论文编写规则，编号与现行版本待核对入库）→ 学校模板 profile**（字体字号、页边距、行距、页眉页脚、封面声明页要素）；不符合项挂条款/模板条目。学校 profile 支持用户自定义导入。

#### 12）术语与数字用法一致性审计（C）

自定义术语表（标准写法↔变体清单，含中英文混排）+ GB/T 15835-2011《出版物上数字用法》规则（编号待核对入库）→ 全文扫描，每条问题挂术语表条目或国标条款；统计报告（变体分布热区）。

#### 13）AIGC 痕迹自检（D，风险提示版）

本地启发式特征：句长均匀性、模板连接词与高频句式密度、AI 高频词表（特征规则逐条挂依据入库）→ 段落级风险清单与全文风险分布；**伦理边界：风险提示≠AIGC 判定，报告强制声明，仅供作者自查改写**；不提供降重/改写功能。

#### 14）综述辅助（E）

文献库内按标题/关键词 TF-IDF 主题聚类 + 年代时间线（复用拓扑可视化）；规则可判的研究空白提示（如"主题 X 近 3 年库内无新增"）；LLM 综述草稿段生成为显式开关扩展项（输出标记为草稿、不入审计结论）。

#### 15）结构检查单（F，并入 11 的条款库框架）

摘要四要素（目的/方法/结果/结论）、关键词数量、每章小结、结论与摘要呼应、章节完整性——挂 GB/T 7713.1 条款的交互式检查单，与格式核查共用 UI。

### 16）内置评测基准（零 API 依赖，含金量核心）

- **文献线**：分层解析 F1、格式检出率/误报率（误报 0）、修正准确率、对账准确率、去重 P/R、幻觉画像检出率、双标尺差异检出率、推荐 Recall@5/MRR、编号重排一致性；
- **全文线**：悬空/幽灵标记检出率（合成 docx 植入）、样式核查检出率/误报率、术语一致性检出率、**AIGC 植入检出率（干净文本程序化植入已知 AI 模式）**、综述聚类与预分组对账；
- 合成论文 docx 模板生成器（样式错误/悬空标记/术语变体/AI 模式四类植入+真值）；指标表写进 README。

## 六、边界与非目标

- **不做**：查重与降重；病句改写与润色；答辩 PPT；文献真伪最终判定与学术诚信结论（画像/自检均为风险提示，报告强制声明）；联网抓取元数据自动补全（仅 DOI 验证、语义 rerank、arXiv 见刊提示三个显式开关扩展项）；反向引用推荐只从库内选取。
- **条文纪律**：四层规则集逐条挂编号+条号+原文摘录+status；查不到原文标"待核对"不得落库、不得生效；AIGC 启发式特征逐条挂依据，不使用黑盒模型。
- **隐私红线**：全本地存储零上传；联网开关仅发送 DOI/选中句必要文本并在设置明示。
- **免责**：审计与提示结果供参考，格式与真实性以学校/期刊及原文为准（报告强制声明）。
- **品牌隔离**：不复制姊妹项目代码；文档不提其余项目业务领域。
