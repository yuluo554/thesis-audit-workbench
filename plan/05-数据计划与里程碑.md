## 一、数据目录规划

| 目录 | 内容 | 入仓策略 |
|---|---|---|
| `data/samples/` | 手工小样例（各输入格式各一份） | 入仓 |
| `data/frozen/` | 生成器产出的字节冻结 fixtures（文献表/合成 docx/真值） | 入仓**禁手改**；改体例=固定 seed 重新生成整目录提交 |
| `data/knowledge/` | 条款库 JSON（GB/T 7714-2015/2025、GB/T 7713.1、GB/T 15835、ISO 26324） | 入仓；每条挂出处+status；查不到=待核对不生效 |
| `data/rulesets/` | 规则包 JSON（四层：国标/年份/期刊/学校 profile） | 入仓；学校 profile 提供导入模板 |
| `data/bench/halluref/` | HalluRef-Bench 公开幻觉文献基准 | 随仓发布（公开范围 M1 定稿，D-4） |
| `data/**/_private/` | 用户私有材料 | **不入仓**（.gitignore） |

## 二、生成器设计（M1 核心资产）

**确定性纪律**（先行声明，实现时逐条配守门）：
- 禁 stdlib random / set 迭代序 / 系统时钟 → 自研 splitmix64 RNG（`taw.rng`），固定 seed 跨版本序列一致；
- 落盘产物**无时间戳**，两次运行**逐字节一致**（`--force` 再生成位级一致守门测试）；
- fixtures 整目录入仓 + "冻结文件出现 CR 即大声失败"守门（对抗 Windows autocrlf 检出污染）。

| 生成器 | 产出 | 植入维度 | 真值 |
|---|---|---|---|
| `gen_references.py` | 文献表（txt/csv/bib/ris 四格式） | 五类条目（期刊/会议/学位/图书/报告）× 噪声分层（无噪/轻噪/强噪：断行、连字符断裂、全半角混排、空格伪影）× 错误注入（标点/缺项/类型标识/著者数/编码制混用/结构矛盾） | 逐条主期望 + also_expect |
| `gen_thesis_docx.py` | 合成论文 docx（样式/正文/图表公式） | 四类植入：样式错误 / 悬空标记 / 术语变体 / AI 模式 | 逐处植入位置+类型 |

- 合成内容全部虚构：作者/刊名虚构，DOI 用 `10.9999/` 假前缀并登记白名单；学校名/作者名/学号虚构；
- AIGC 基准：干净基线文本 + 程序化植入已知 AI 模式（句式模板清单随生成器落盘）；
- 生成器模块注释写清**真值语义**（主期望/also_expect 对账口径，见 04 §七）。

## 三、条文查证计划（M1 内完成或显式挂起）

| 依据 | 动作 | 失败降级 |
|---|---|---|
| GB/T 7714-2015 / 2025 条文 | 官方渠道 curl 落盘后本地提取（禁摘要工具转述；JS 渲染站走 API 端点） | 两渠道全败 → 条目标 `pending` 继续推进，渠道记入决策记录 |
| GB/T 7713.1 编号与现行版本 | 同上 | 同上 |
| GB/T 15835-2011 编号 | 同上 | 同上 |
| ISO 26324 / Crossref 文档 | 官方原文核验 | 同上 |

纪律：模型内部记忆只用于定位"查哪部规范哪个条号"；数值与条文以官方原文为准；**搜索通道可能被污染**（WebSearch 摘要一律不采信）。
