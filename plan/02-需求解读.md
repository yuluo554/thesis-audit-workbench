## 三、非功能需求（NFR）

| NFR | 要求 | 落点 |
|---|---|---|
| NFR-01 | 离线即用；联网仅 DOI 核验/语义 rerank/arXiv 提示三个显式开关扩展项 | 引擎不引网络依赖；联网模块惰性导入+设置明示 |
| NFR-02 | 确定性可复现：生成器固定 seed、落盘产物无时间戳、两次构建位级一致、基准零 API | 自研确定性 RNG（splitmix64），禁 stdlib random/时钟/set 迭代序 |
| NFR-03 | 隐私红线：全本地存储零上传 | 无遥测；联网开关发送内容在设置明示 |
| NFR-04 | 条款溯源：每条结论挂编号+条号+原文摘录+status | 规则包 schema 强制字段；无出处不得落库生效 |
| NFR-05 | 三级判定 pass/fail/manual_confirm；多值/低置信度不硬判 | 判定 schema + 报告模板 |
| NFR-06 | Windows 一等公民（win10+），CI 保 ubuntu/windows 可移植 | 打包 onedir exe；CI 四矩阵 |
| NFR-07 | 演示产物 0 外链断网可开（拓扑 HTML/报告/演示样例） | pyvis in_line + 守门测试断言 |
| NFR-08 | Python 3.8 兼容写法（本机 3.8.8 为开发基线） | typing.Optional / __future__ annotations；CI py3.8 矩阵把关 |

## 四、边界与非目标（工程守卫形式）

题目 §六 转译为可执行的守卫，违反 = 回归：

1. **不做**：查重与降重、病句改写润色、答辩 PPT、文献真伪最终判定与学术诚信结论、联网抓取元数据自动补全；
2. **推荐防幻觉**：反向引用推荐候选只能来自已审计库内文献（引擎层结构保证，非提示词约定）；
3. **条文纪律**：规则未挂编号+条号+原文摘录+status 不得落库、不得生效；查不到原文标"待核对"；
4. **AIGC 伦理边界**：特征逐条挂依据、不用黑盒模型；报告强制声明"风险提示≠AIGC 判定"；不提供降重/改写功能；
5. **免责声明**：审计结果供参考，格式与真实性以学校/期刊及原文为准——报告模板硬编码强制声明。
