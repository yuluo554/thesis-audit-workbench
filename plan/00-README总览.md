## 里程碑（初稿，v2 口径）

- M1 数据先行：五类文献模板 × 噪声等级 × 错误类型（含结构矛盾型）合成生成器 + 两版规则集骨架 + 数据台账
- M2 解析层：噪声鲁棒解析（分层 F1 回归）
- M3 核查与修正引擎：条款溯源 + diff 修正 + 教学解释面板
- M4 对账/归一/画像：正文引用对账引擎、重复归一、结构风险画像（DOI 本地校验）
- M5 可视化与交付：论证链矩阵 + pyvis 拓扑（0 外链）+ 文献库 + PySide6/CLI + PyInstaller
- M6 脱敏发布 GitHub + Release（exe）+ 收尾固化
